# RoomLab
- A local first 3D room planner: keep dimensions true to scale, use metres, and keep prices in whole illustrative euros.
- Keep placement, fit and price calculations separate from the 3D scene. Run `npm test` and `npm run build` after changing behavior.
- For interaction changes, check the 3D and floor plan views, keyboard controls and a narrow viewport in a real browser.
- Keep controls legible and immediate. Use movement to show what changed. Furniture and room take visual priority.
- Use original or properly licensed assets and record their source. Use standalone sample data. Keep external publishing as a separate step.
